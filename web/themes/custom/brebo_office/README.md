# BREBO Office theme

Versie 0.1.0. Centraal applicatietheme voor BREBO Office.

- UI-lettertype: Roboto met Arial als tijdelijke fallback.
- Documentlettertype blijft Verdana.
- Statussemantiek en presentatiepatronen worden centraal beheerd.
- Leidende UI/UX-specificatie: `docs/BREBO_OFFICE_UI_DESIGN_SYSTEM.md`.
- Functionele modules leveren inhoud en gedrag; dit theme bepaalt samen met het design system de consistente presentatie.
- Modules introduceren geen eigen visuele taal of parallel theme zonder expliciet vastgelegde uitzondering in het design system.

Het theme implementeert stapsgewijs de centrale componenten voor cockpits, dossiers, lijsten/kanban, formulieren, look-ahead/risico, statusbadges en foto/bewijsweergave.
