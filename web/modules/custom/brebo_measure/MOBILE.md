# Mobile handoff v0.1

The mobile client should remain deliberately thin:

1. receive/select an Office opening;
2. create or resume a measurement assignment;
3. start a capture with device metadata;
4. guide the operator around the opening;
5. send individual observations with provenance and uncertainty;
6. capture independent control dimensions as separate observations;
7. return the dossier to Office for validation.

The phone is a sensor and capture interface. BREBO Office owns the opening identity, history, validation and later production release.
