# Endpoint quick reference

- `GET /brebo-office/api/measure/openings/{opening_id}`
- `POST /brebo-office/api/measure/openings/{opening_id}/assignments`
- `POST /brebo-office/api/measure/assignments/{assignment_id}/captures`
