# Measure-02 acceptance

The increment is acceptable when:

- it starts from the merged Measure-01 domain;
- Office exposes a minimal authenticated API for opening -> assignment -> capture -> observation;
- sensor and control measurements can coexist without overwrite;
- source/device/confidence/uncertainty remain traceable;
- the contract is not Apple-specific;
- field validation and production approval remain separate concepts;
- PHP quality gate passes.
