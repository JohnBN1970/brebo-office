# Initial observation keys

The first field client may use these stable semantic keys:

- `opening.width.top`
- `opening.width.middle`
- `opening.width.bottom`
- `opening.height.left`
- `opening.height.middle`
- `opening.height.right`
- `opening.diagonal.a`
- `opening.diagonal.b`
- `opening.kalf.height`
- `opening.stile.position`
- `opening.reveal.depth`
- `opening.sill.level`

Values remain source-neutral. Method, provenance, confidence and uncertainty describe how each value was obtained.
