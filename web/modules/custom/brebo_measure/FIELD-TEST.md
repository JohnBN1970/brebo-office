# First real opening test card

Use a real opening where repeated access is easy.

Run at least five captures of the same opening. For every run store width top/middle/bottom, height left/middle/right, diagonals where available, kalf/stile points where applicable, device pose/quality, photos and independent reference dimensions.

Do not average away bad captures. Keep every run so repeatability and operator effects remain visible.

The first result is not pass/fail for LiDAR as a technology. It is evidence per measurement feature and site condition for the A/B/C/D decision in `WORKFLOW.md`.
