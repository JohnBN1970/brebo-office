# First field go/no-go

After the initial repeated opening tests answer:

1. Are primary dimensions repeatable enough to continue mobile-first?
2. Which features show systematic bias versus reference?
3. Which features need a simple physical reference?
4. Which features genuinely require precision hardware?
5. Is the total field + Office workflow faster than the current process?
6. Does the dossier prevent missing-data callbacks or second visits?

Hardware design starts from these answers, not from assumptions.
