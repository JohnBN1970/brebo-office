# First usable run

The first end-to-end run should be deliberately small:

1. select/create one opening in Office;
2. create an assignment;
3. create an `apple_lidar` capture;
4. submit width/height observations;
5. submit one independent laser/control observation for the same key;
6. inspect both values in Office and calculate the difference;
7. repeat the capture at least five times.

That is enough to begin answering whether the mobile measurement route is practically useful.
