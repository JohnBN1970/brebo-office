# First practical BREBO Measure loop

The next product gate is not a polished app. It is one real opening measured at a BREBO test location and visible in Office.

For each test opening record:

- capture duration;
- LiDAR/depth observations;
- independent laser or manual reference observations;
- difference in millimetres;
- operator corrections;
- missing geometry/details;
- whether a second visit would have been necessary;
- Office review time.

The first decision after real data is collected is classification by feature:

- A: mobile measurement is sufficient;
- B: mobile plus a simple physical reference is sufficient;
- C: precision hardware is required;
- D: human review is required.

A green development capture is not a production release. Production dimensions remain a separate approval step.
