# First physical field test

Target: one simple rectangular opening with solid, clearly visible reveals/edges.

1. Measure independent reference width and height with a trusted laser/tape and record in millimetres.
2. Open BREBO Measure POC and start the automatic scan.
3. Do not tap endpoints.
4. Move slowly around the full opening, keeping left/right/top/bottom boundaries visible from more than one viewpoint.
5. Stop only after the app reports sufficient spatial data.
6. Repeat the complete scan ten times, changing the starting position slightly each time.
7. Compare detected dimensions, spread and deviation against the independent reference.

For the first baseline, avoid making glass/reflections the only visible boundary. Difficult glazing cases come after the solid-frame baseline.

A successful cloud build or a visually plausible AR mesh is not an accuracy result.
