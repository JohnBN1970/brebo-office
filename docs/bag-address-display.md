# BAG address display convention

BREBO Office keeps BAG house-number components structured in storage and only formats them for display.

- house number only: `87`
- house letter: `87H`
- numeric/alphanumeric addition: `87-1`
- house letter plus addition: `87H-1`

The formatter must never make an addition look like part of the base house number (for example `871` when the BAG data means house number 87, addition 1).
