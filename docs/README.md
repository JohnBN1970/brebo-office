# BREBO Office-documentatie

Deze map bevat de bestuurlijke en technische documentatie van BREBO Office.

## Documenten

| Document | Doel |
| --- | --- |
| [Roadmap](ROADMAP.md) | Mijlpalen, actuele fase en eerstvolgende ontwikkelstappen |
| [Wijzigingsregister](WIJZIGINGSREGISTER.md) | Herleidbare vastlegging van belangrijke wijzigingen en besluiten |
| [BMS-backlog](BMS_BACKLOG.md) | Geprioriteerde proces- en ontwikkelopgaven |
| [Technische architectuur](ARCHITECTUUR.md) | Hoofdlijnen van de technische inrichting en beheersmaatregelen |
| [Test- en acceptatiedossier](TEST_EN_ACCEPTATIE.md) | Bewijs van controles, testresultaten en resterende acceptatiepunten |

## Documentprincipes

- Het BMS beschrijft de bedrijfsprocessen; technische implementatiedetails staan in de architectuurdocumentatie.
- AI-uitvoer is ondersteunend en blijft een concept totdat een bevoegd persoon deze heeft beoordeeld.
- Vastgestelde missie, visie en werkprincipes worden alleen via een afzonderlijk besluit gewijzigd.
- Elke gerealiseerde technische mijlpaal wordt herleidbaar gekoppeld aan een commit en testbewijs.

Laatst bijgewerkt: 10 augustus 2026.
